# /privacy-legal:dsar-response

Draft a response to the data subject rights request provided.

## Instructions

1. Apply the dsar-response skill framework.
2. Identify the request type (access, erasure, portability, objection, etc.) and applicable law.
3. Calculate the response deadline from the receipt date provided (or flag it as unknown).
4. Work through the checklist:
   - Identity verification: complete? If not, what is needed?
   - Exemptions: do any apply? Document the analysis.
   - Data scope: what systems should be searched?
5. Draft the response letter using the template from the dsar-response skill.
6. Flag any aspects requiring attorney or DPO sign-off.

If the request text is not provided, ask the user to paste it or describe the request.

## Output

Produce:
1. **Intake summary** (request type, deadline, identity verification status)
2. **Exemption analysis** (with regulatory citations for any exemptions applied)
3. **Draft response letter** (ready for attorney/DPO review)

> **Attorney/DPO review required.** Do not send this response without sign-off from qualified legal counsel or your DPO.
