# /commercial-legal:triage-nda

Rapidly triage the NDA or confidentiality agreement provided.

## Instructions

1. Apply the nda-triage skill framework.
2. Determine: one-way or mutual, disclosing and receiving parties.
3. Complete the deviation table comparing this NDA to market-standard positions.
4. Assign traffic-light ratings: 🔴 High concern / 🟡 Moderate / 🟢 Acceptable.
5. List recommended negotiation points in priority order.

Focus on **deviations from standard** — do not re-explain boilerplate that is market standard.

If no NDA is provided, ask the user to paste the text or share the file path.

## Output

Deliver the NDA triage report in the structured format defined by the nda-triage skill. End with:

> **Attorney review required.** This triage is a draft prepared by AI. Engage qualified legal counsel before signing or negotiating.
